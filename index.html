Backend thinking

Example API endpoint pattern

Illustrative C# only. This small example shows request validation and a clear response shape; a production implementation would also include authorization, logging, service-layer rules, persistence, and tests appropriate to the application.

ASP.NET Core minimal endpoint (illustrative)

app.MapPost("/api/service-requests", (
    CreateServiceRequest request) =>
{
    if (string.IsNullOrWhiteSpace(request.Description))
    {
        return Results.ValidationProblem(
            new Dictionary<string, string[]>
            {
                ["description"] =
                    ["Enter a description of the request."]
            });
    }

    // Delegate to an application service in production.
    return Results.Accepted(value: new
    {
        status = "received",
        message = "Request accepted for processing."
    });
});

public sealed record CreateServiceRequest(
    string Description);

This snippet is a discussion sample, not a complete or deployed API. It has not been connected to a database or execution environment.
